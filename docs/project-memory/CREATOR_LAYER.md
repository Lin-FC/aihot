# Creator Layer

Creator opportunity analysis is Story-level, never Article-level. Multiple reports grouped into the same real-world Story therefore produce one current opportunity, with append-only analysis history.

Automatic V1-A eligibility requires an unmerged Story with a non-empty digest, activity in the last 72 hours, and at least one selected public publication. Analysis becomes stale when the Story version or Creator prompt version changes; Heat changes alone do not trigger analysis.

V1-A produces independent WeChat, Xiaohongshu, Douyin, and commercial scores plus intents, type, lifecycle, audience, angles, monetization types, reasoning, and offer ideas. Attention and Heat remain separate AIHOT signals displayed at read time. There is no combined Content Score or Priority Score.
