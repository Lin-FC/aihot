# Decisions

- AIHOT Core stays independently maintainable.
- The Creator Layer starts from Story.
- Creator analysis is Story-level, not Article-level.
- V1 has no combined public Content Score.
- Opportunity analysis is automatic; full content generation remains human-triggered in later phases.
- V1-A does not publish to social platforms.
- Opportunity analysis history is append-only; manual re-analysis appends a row.
- Heat is a live display signal and does not make an analysis stale.
